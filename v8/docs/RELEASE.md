# Release Notes (V7.0.0 -> V8.1.0)

Diese Seite sammelt die funktionalen Meilensteine in Reihenfolge.

## V7-Linie
- `V7.0.0`: Isolierter `v7/`-Stack mit eigenen Ports und kompletter Runtime.
- `V7.1.0`: Hands-free Listen Mode mit Auto-Resume und persistierten User-Defaults.
- `V7.2.0`: Audio-Pipeline-Hardening (ffmpeg-Konvertierung + robuste JSON-Fehler).
- `V7.3.0`: GitHub-Interaktion und Release-Flow weiter automatisiert.
- `V7.4.0`: Admin-Setup und Betriebsfokus erweitert.
- `V7.5.0`: Doku/Help-Menue konsolidiert und ausgebaut.
- `V7.6.0`: Weitere Stabilisierung von Flows und Bedienlogik.
- `V7.7.0`: Monitoring/Observability-Verbesserungen.
- `V7.8.0`: Admin- und Test-Workflows erweitert.
- `V7.9.0`: Protokoll-/Template-Verbesserungen.
- `V7.10.0`: Help-Menue + Token-Gate + Gesamtzusammenfassung V7.

## V8-Linie
- `V8.0.0`: Neues isoliertes `v8/`-Scaffold mit Valkey-Sidecar und EventBus-Skeleton.
- `V8.1.0`: Trennung in Admin UI (`8082`) und Customer UI (`8083`) plus `POST /api/chat/text`.
