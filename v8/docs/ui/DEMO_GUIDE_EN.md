# Demo Guide (EN) - V8.10.2

## Story-Flow 1: Customer + Virtual Agent (Wallbox)
**Have you ever seen a simple support question suddenly become technical?**
1. Customer explains a wallbox issue.
2. Agent provides structured next steps.
3. Set TTS Output Language to `en` or `de`.
4. Show: original answer + translated answer + spoken translated output.

## Story-Flow 2: Healthcare Triage (non-emergency)
**Have you ever needed quick guidance before booking care, without it being an emergency?**
1. Customer describes symptoms for appointment triage.
2. Agent helps with practical next steps.
3. Always state the disclaimer:
   - "This is not an emergency line. In case of emergency call 112."

## Story-Flow 3: Admin Live Demo
**Have you ever needed to prove stability and observability in front of stakeholders?**
1. Show metrics (STT/LLM/Translation/TTS/Total).
2. Switch backend/model and compare latency.
3. Export transcript.
4. Delete session/user and demonstrate controlled reset.
