# Demo Guide (V8.3.0)

## Story: Schnell den richtigen Kundenfall finden
"Stell dir vor, du uebernimmst als Agent und brauchst in Sekunden den richtigen Fall."

1. Kunde sendet eine Nachricht in `8083`.
2. Agent oeffnet `8084`.
3. In der Suche User-ID oder Session-ID eingeben.
4. Session sofort anklicken, Join ist direkt aktiv.
5. Agent antwortet, Kunde sieht Antwort live.

## Buehnenwirkung
- Start: viele offene Sessions, hoher Druck.
- Wendepunkt: Suche findet exakt den Fall.
- Ende: kontrollierte Uebergabe mit Live-Antwort.
