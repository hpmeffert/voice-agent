# Help (V8.0.0)

Diese Seite erklaert die Benutzerfunktionen.

## Wo finde ich was?
- `Record` startet die Aufnahme.
- `Stop` beendet die Aufnahme.
- `Send` sendet die Aufnahme an `/api/voice`.
- `Clear Session` startet einen neuen Dialogkontext.

## Wichtige Einstellungen
- `Silence threshold (ms)` Standard ist `1300`.
- `Auto-stop` und `Auto-send` steuern den halbautomatischen Ablauf.
- `TTS language` steuert die Ausgabesprache.

## Status
- `idle`, `recording`, `sending`, `thinking`, `speaking`, `listening`.
