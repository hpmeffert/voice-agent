# Demo Guide (DE) - V8.10.2

## Story-Flow 1: Kunde + virtueller Agent (Wallbox)
**Kennen Sie das auch, wenn eine einfache Frage ploetzlich technisch wird?**
1. Kunde beschreibt ein Problem bei der Wallbox.
2. Agent antwortet strukturiert mit naechsten Schritten.
3. TTS Output Language auf `en` stellen.
4. Zeigen: Originalantwort + Uebersetzung + gesprochene EN-Ausgabe.

## Story-Flow 2: Gesundheitsbereich (Triage, kein Notfall)
**Kennen Sie das auch, wenn schnell Orientierung gebraucht wird, aber kein Notfall vorliegt?**
1. Kunde schildert Symptome fuer Terminplanung.
2. Agent hilft bei Priorisierung und naechsten Schritten.
3. Wichtiger Hinweis live sagen/zeigen:
   - "Dies ist keine Notfall-Hotline. Im Notfall 112 anrufen."

## Story-Flow 3: Admin Live Demo
**Kennen Sie das auch, wenn ein Team wissen will, ob wirklich alles stabil laeuft?**
1. Admin zeigt Metrics (STT/LLM/Translation/TTS/Total).
2. Backend/Model wechseln und Laufzeiten vergleichen.
3. Transcript exportieren.
4. Session oder User loeschen und erneuten Start zeigen.
