# Export Templates (V7.4.0)

This folder contains CRM transcript export templates owned by this repository (MIT project default).

Files:
- `transcript_default.md.tpl`
- `transcript_default.json.schema.json`

Placeholders in `transcript_default.md.tpl`:
- `{{date}}`
- `{{weekday}}`
- `{{start_time}}`
- `{{end_time}}`
- `{{user_id}}`
- `{{session_id}}`
- `{{backend}}`
- `{{model}}`
- `{{lang}}`
- `{{messages}}`

Notes:
- Keep templates text-only.
- Do not place binary assets in this directory.
