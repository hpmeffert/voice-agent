# Transcript Templates (V6.4.1)

Default Markdown transcript template:
- `transcript_default.md.tpl`

Supported placeholders:
- `{{date}}`
- `{{weekday}}`
- `{{start_time}}`
- `{{end_time}}`
- `{{user_id}}`
- `{{session_id}}`
- `{{backend}}`
- `{{model}}`
- `{{lang}}`
- `{{messages}}`

Message block format is rendered by API and injected into `{{messages}}`.
